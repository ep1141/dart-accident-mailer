# DART 중대재해 발생사실 공시 모니터링

평일 09시~18시(KST) 매시 정각에 OpenDART API로 전 기업 공시를 확인하여, 보고서명에 "중대재해"가 포함된
신규 공시가 있으면 사고내역(발생 장소·발생 재해 내용·사망자 수·부상자 수·발생일자·고용노동부 보고일자·
조치사항 및 향후대책)을 추출해 HTML 메일로 즉시 발송합니다. 신규 건이 없으면 메일을 보내지 않습니다.

## 동작 방식

1. `list.json`(공시검색)으로 최근 3일 공시 목록을 전부 조회 (주말·연휴·지연 대비)
2. 보고서명 키워드 필터 → `state/sent.json`에 없는 건만 신규로 판단
3. `document.xml`(원본파일)로 공시 원문을 받아 표를 파싱, 제11-3-16조 서식 항목을 요약 추출
4. **같은 사고 중복 병합**: 자회사와 모회사가 같은 사고를 각각 공시한 경우(재해 내용·발생일자 동일)
   자회사 직접 공시 한 건만 남기고, 모회사 공시는 카드 상단에 "같은 사고 공시" 링크로 표기.
   이미 발송한 사고의 모회사 공시가 뒤늦게 올라와도 다시 보내지 않음
5. Gmail SMTP로 발송 후 발송 이력(공시번호·사고 키)을 저장소에 커밋

### 실행 시간대

- cron은 `0 0-9 * * 1-5`(UTC) = 평일 09~18시 KST 매시 정각
- GitHub cron이 지연되어 그 외 시간에 시작되더라도, 첫 단계에서 KST 기준 요일·시각을 확인해
  평일 09~18시가 아니면 아무것도 하지 않고 종료
- 18시 이후·주말에 올라온 공시는 다음 영업일 09시 실행에서 발송
- 한국 공휴일은 구분하지 않음 (평일 공휴일에도 실행)

### 메일 형식

- 제목: `[CSO 중대재해 공유] 11/10 XX건설, XX로보틱스` (해당 기업명 나열, 120자 초과 시 말줄임)
- 본문: 기업별 카드 → 공시명·제출인·DART 원문 링크 → 요약 표
- 한글 카드 아래에 **영문 번역본**을 병기 (발생 장소·재해 내용·사망/부상자 수·조치사항 등 요약 항목).
  Anthropic API(Claude Haiku)로 번역하며, `ANTHROPIC_API_KEY` 시크릿이 없거나 번역이 실패하면
  영문 부분만 생략하고 한글 메일은 정상 발송
- 공시 원문 표는 요약 추출에 실패한 경우에만 대신 표시
- 정정공시(`[기재정정]`)와 중대재해 관련 형사처벌 확인 공시도 포함

## 설정 (GitHub Actions)

1. 이 폴더를 GitHub 저장소(private 권장)로 푸시
2. **Settings → Secrets and variables → Actions → Secrets** 에 등록
   | 이름 | 값 |
   |---|---|
   | `DART_API_KEY` | OpenDART 인증키 (https://opendart.fss.or.kr 가입 후 발급, 즉시 발급됨) |
   | `SMTP_USER` | 발신 Gmail 주소 |
   | `SMTP_PASS` | Gmail **앱 비밀번호** (Google 계정 → 보안 → 2단계 인증 → 앱 비밀번호) |
   | `MAIL_TO` | 수신자, 쉼표 구분 |
   | `ANTHROPIC_API_KEY` | (선택) 영문 번역용 Anthropic API 키. 없으면 한글 메일만 발송 |
3. (선택) **Variables** 에 `KEYWORDS` 등록으로 필터 키워드 변경 (예: `중대재해,산업재해`)
4. **Actions** 탭 → "DART 중대재해 공시 모니터링" → **Run workflow**
   - `dry_run` 기본값은 `1`(미발송 테스트). 실제 발송 테스트는 `0`으로 변경
   - `lookback_days`를 늘리면 과거 건도 조회 (90일 조회는 약 30분 소요)
   - 수동 실행은 시간대 제한 없이 동작
   - 테스트 결과는 `preview/preview.html`로 저장소에 커밋되고 Artifacts에도 업로드됨
5. 이후 매 평일 09~18시 자동 실행

## 로컬 테스트

```bash
pip install -r requirements.txt
copy .env.example .env   # 값 채우기
# PowerShell
Get-Content .env | ForEach-Object { if ($_ -match '^(\w+)=(.*)$') { $env:($matches[1]) = $matches[2] } }
$env:LOOKBACK_DAYS="30"; python dart_monitor.py
```

## 상태 파일 (`state/sent.json`)

- `sent`: 발송(또는 중복 병합)으로 처리한 공시번호 목록
- `keys`: 발송한 사고 키 (`원/정정|발생일자|재해내용 정규화`) — 모회사 후속 공시 중복 방지용
- 최근 2,000건만 유지

## 주의

- GitHub cron은 정각보다 수 분~수십 분(드물게 수 시간) 늦게 실행될 수 있습니다. 시간대 게이트로 근무시간 외 발송은 막습니다.
- OpenDART 인증키는 일 10,000회 호출 제한이 있습니다. 하루 10회 실행 기준 호출은 100~200회 수준입니다.
- 저장소에 60일간 커밋이 없으면 GitHub가 예약 실행을 중지합니다. 발송 때마다 이력이 커밋되므로 두 달간 공시가 전혀 없을 때만 해당하며, Actions 탭에서 다시 켤 수 있습니다.
- Gmail 앱 비밀번호를 삭제하거나 계정 비밀번호를 변경하면 발송이 실패합니다. 새 앱 비밀번호로 `SMTP_PASS`를 갱신하세요.
- 공시 제목에 "중대재해"가 없고 본문에만 언급된 건은 검출되지 않습니다.
